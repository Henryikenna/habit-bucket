# Habit Bucket

Habit Bucket is a clean, lightweight habit-tracking app focused on **consistency over clutter**. It helps you build daily, weekly, monthly, and yearly habits with automatic resets, streak tracking, and a modern, distraction-free UI.

## ✨ Features

* Create **daily, weekly, monthly, and yearly habits**
* One-tap habit check-off
* **Automatic reset** based on habit frequency
* Streak tracking to keep momentum
* Stats screen with progress insights
* Designed for a future **Spotify-style year-end Wrapped**

## 🧠 Philosophy

Most habit apps overwhelm users. Habit Bucket keeps things simple:

* Fast habit creation
* No manual resets
* No guilt-driven UX
* Clean visuals and satisfying interactions

## 🛠️ Tech Stack

* **Flutter**
* FontAwesome Icons
* Custom reusable UI components

## 🚧 Status

This project is actively under development. Core habit flows and UI are in place, with stats enhancements and year-end summaries planned.
